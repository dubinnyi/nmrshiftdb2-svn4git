Spectrum Viewer Applet

Features:
  • the applet can handle atoms with identical chemical shift (isochrone atoms), see methyl grooups in example
  • different display options (can be specified by applet parameters):
    • display nmr spectrum with realistic lines or as histogram
    • provides a J-modulation view
    • display peak multipletts (if provided as input, without info nothing is displayed)
    • display integral
    • show or hide a navigation view (default: 250ppm to -10ppm)
    • automatic to scale the intensity to visible peaks
    • enable/disable simulation of a 'Roof-Effect', Example: see roofEffect.html
  • zoom in/out:
    RIGHT MOUSE BUTTON: define zoom range, LEFT DOUBLECLICK: reset zoom
  • calculate distance: hold left mouse button pressed and move the mouse, the distance is displayed
  • interactive change of spectrometer frequency
  • show info about peak under cursor
  • show prediction distribution for peak under cursor: if peak highlighted => press a key
    Example: see prediction.html
  • interaction with Marvin spectrum applet (works only with an unsignet version of marvin.jar)
  • keyboard actions (renderer must have focus):
    • if a peak is highlighted:
      any key pressed will display prediction histogram (if available)
    • [ + ] or [ - ] key:
      increase/decrease spectrometer frequency
    • [ * ] or [ / ] key:
      increase/decrease zoom in y-direction (reset during 'normal' zoom actions)
    • [ L ] key:
      if prediction AND experimental spectrum are displayed toggle display of correlation lines
    • [ F ] key:
      for 13C spectrum: toggle display of colored peaks in histogram mode (color for multiplicity, only for peaks with one coupling)
    • [ D ] key:
      toggle display mode (realistic or histogram)
    • [ C ] key:
      toggle display of peak couplings
    • [ J ] key:
      toggle display of 'J-Modulation' / 'Peak phase'
    • [ I ] key:
      toggle display of integrals
    • [ N ] key:
      toggle display of navigation spectrum
    • [ R ] key:
      for 1H spectrum: toggle display of roof effect

  • The following paramaters can be set in applet:
      • Required parameters:
    • <param name="spectrum" value= "...">
           data for spectrum (normally the predicted spectrum),for detailed info about input formats see inputFormats.html
    • <param name="structureRenderer" value= "MView1">
           the name of the structure viewer applet (Marvin/JChemPaint), this parameter is required if interaction with structure renderer is enabled

      • Optional parameters:
    • <param name="spectrumTyp" value= "13C">
           13C: 13C-spectrum [default]
           1H: 1H-spectrum
    • <param name="spectrumExperiment" value= "...">
           data for the experimental spectrum, displays two detailed spectrum views, e.g.see demoExperimental.html
      for detailed info about input formats see inputFormats.html
    • <param name="showCorrelation" value= "true">
           true: show correlation lines between experimental and predicted spectrum [default]
           false: show no correlation lines
      Example: see correlation.html: correlation enabled
    • <param name="solvent" value= "CDCL3">
           the solvent used, solvent parameters are stored in 'spec.properties'
      Example: see antTest.html
    • <param name="frequency" value= "100">
           the spectrometer frequency in MHz (default=100), accepts double values.
           All other strings forces 'unknown' frequency and usage of default frequency (100 MHz),
           e.g.see experimental spectrum in demoExperimental.html
    • <param name="lineWidth" value= "1">
           the peak line-width in Hz (defaults: 13C=1Hz, 1H=0.5Hz)
      Example: see TestButadiene.html
    • <param name="predictions" value= "...">
           for detailed info about input formats see inputFormats.html; Example: see prediction.html
    • <param name="realisticLines" value= "true">
           true: show realistic lines (Lorentz) in spectrum [default]
           false: show peaks as histogram
    • <param name="jModulation" value= "false">
           true: show j-modulated spectrum ('Spin-Echo')
           false: show standard spectrum [default]
    • <param name="coloredPeaks13C" value= "true">
           true: in 13C-spectra peaks are colored using their multiplicity (onyl peaks with one coupling!), if 'showCoupling=true' coloring is disabled. [default]
           false: no colored peaks
      Example: see colored13C_histo.html
    • <param name="showCoupling" value= "false">
           true: show peaks as multipletts, requires multiplicity info as input
           false: show single peak lines [default]
    • <param name="showRoofEffect" value= "false">
           true: show peak multipletts with simulated 'Roof-Effect'
           false: show peak multpletts without 'Roof-Effect' [default]
    • <param name="showIntegral" value= "true">
           true: show integral in spectrum
           false: don't show integral [default]
    • <param name="hideNavigation" value= "true">
           true: hide the navigation view
           false: show he navigation view [default]
    • <param name="autoIntensity" value= "false">
           true: autoscale for intensity, maximum size for visible peaks
           false: no autoscale for intensity [default]

  • Two implementation of the applet exist:
    • One version that supports interaction with Marvin/JChemPaint structure viewer:
      Reqirements:
      - both applets must use archive="spectrumapplet.jar,jmarvin_unsigned.jar" (or analog jars for JChemPaint), otherwise different classloaders are used
      - the marvin.jar must be an unsigned version
      Example:
           <applet name="Spectrum1" code="SpectrumView.class"
           ( for JChemPaint: <applet name="Spectrum1" code="org/openscience/nmrshiftdb/spectrumapplet/SpectrumView.class" )
           archive="spectrumapplet.jar,jmarvin_unsigned.jar"
           width="350" height="250">
           <param name="spectrum" value= "30.8;0.0;8q|30.8;0.0;9q|30.8;0.0;10q|">
           <param name="structureRenderer" value= "MView1" >   <== REQUIRED !!
           </applet>
    • A second version without interaction with Marvin/JChemPaint structure viewer:
      Example:
           <applet name="Spectrum1" code="org/openscience/nmrshiftdb/spectrumapplet/SpectrumViewNoRenderer.class"
           archive="spectrumapplet.jar"
           width="350" height="250">
           <param name="spectrum" value= "30.8;0.0;8q|30.8;0.0;9q|30.8;0.0;10q|">
           </applet>

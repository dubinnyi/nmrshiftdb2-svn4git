13C-Spectra


For 13C-spectra the following formats are supported:

a) The format used by NMR-ShiftDB, e.g.: "197.74d;0.0;1|143.55;0.0;0|27.36;0.0;2t|"
  • Each peak is specified by: "SHIFTVALUE;INTENSITY;ATOMNUMBER" (separated by semicolon)
  • Peak multiplicity is specified by adding the multiplicity information to one of the values, all values within a peak definition are allowed.
  • If peak intensity is 0.0 the program estimates the intensity by using the multiplicity
  • Peaks are separated by '|'
  • ATTENTION: atom number counting starts with 0 (standard for chemical structures is 1)

b) The standard short 'signal' format, e.g.: "S(0.0,0,6,d)=197.74|S(0.0,0,1)=143.55|S(0.0,0,5,t)=27.36"
  • Each peak signal is specified by: "S(INTENSITY,INTEGRAL,ATOMNUMBER,MULTIPLICITY)=SHIFTVALUE"
  • Atomnumber and peak multiplicity are optional, if multiplicity is used the atomnumber must be specified. If no multiplicity is defined the peak is marked as UNKNOWN multiplicicity.
  • If peak intensity is 0.0 the program estimates the intensity by using the multiplicity
  • Peaks are separated by '|'
  • ATTENTION: atom number counting starts with 1 (standard for chemical structures)

c) The standard extended 'signal' format, e.g.: "S(60,1,2)=116.5;J(q-F)=283|S(20,1)=164.4;J(q-F)=44"
  • Each peak signal is specified by: "S(INTENSITY,INTEGRAL,ATOMNUMBER)=SHIFTVALUE"
  • Couplings are specified by: "J(MULTIPLICITY-ELEMENT)=COUPLINGCONSTANT", ELEMENT specifies the chemical element of the coupling partner.'-ELEMENT' is optional, default coupling partner is hydrogen('-H')
  • Atomnumber and peak multiplicity are optional, if multiplicity is used the atomnumber must be specified.
  • If peak intensity is 0.0 the program estimates the intensity by using the multiplicity
  • Signal part and couplings (also multiple couplings) are separated by ';'
  • Peaks are separated by '|'
  • ATTENTION: atom number counting starts with 1 (standard for chemical structures)

13C-Spectra Prediction


For 13C-spectra prediction data the following formats are supported:

a) The format used by NMR-ShiftDB, e.g.: "143.55|142.699;143.600;143.600;143.600;144.369;|197.74|197.0;197.0;197.0;197.0;197.0;197.899|"
  • Each peak prediction is specified by: SHIFT|shift; shift;shift; .."
  • 'SHIFT' specifies the chemical shift of the peak displayed in spectrum (the predicted shift), 'shift' specifies the chemical shifts used for prediction
  • Different peak predictions are separated by '|'
  • ATTENTION: the general disadvantage of this format is the problem that for isochrone atoms it isn't possible to assign a specific prediction to unique atom number

1H-Spectra


For 1H-spetra the standard extended 'signal' format is used, e.g.: "S(1,1,1)=5.06;J(d,2)=1.8;J(d-N,3)=10.2;J(d,4)=-0.9|S(..)=..;J(..)=..."
  • Each peak signal is specified by: "S(INTENSITY,INTEGRAL,ATOMNUMBER)=SHIFTVALUE"
  • Couplings (optional) are specified by: "J(MULTIPLICITY-ELEMENT,ATOMNUMBER)=COUPLINGCONSTANT", ELEMENT specifies the chemical element of the coupling partner.'-ELEMENT' is optional, default coupling partner is hydrogen('-H'). ATOMNUMBER specifies the atom number of the coupling partner
  • If peak intensity is 0.0 the program estimates the intensity by using the integral
  • Signal part and couplings (also multiple couplings) are separated by ';'
  • Peaks are separated by '|'
  • ATTENTION: atom number counting starts with 1 (standard for chemical structures)
(for correct scaling of the navigation view add: <param name="spectrumTyp" value= "1H"> !!)
